# ปราสาทง้อแอร์ 🏰💌

เว็บไซต์น่ารักธีมนิทาน/ปราสาท สำหรับง้อแอร์ เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือจะโฮสต์ผ่าน GitHub Pages ก็ได้

## มีอะไรในนี้บ้าง

- **หน้าปราสาท + น้องจิ้งจอก** เป็นตัวการ์ตูนนำเรื่องตลอดทั้งหน้า พร้อมท้องฟ้ายามค่ำคืนแบบ animate
- **สมุดนิทานง้อใจ** การ์ดข้อความขอโทษ 5 หน้า เลื่อนซ้าย–ขวาได้ (ปุ่มลูกศร หรือปัดจอบนมือถือ)
- **เกมง้อใจ** ปุ่ม "ยังไม่ให้" จะหลบหนีไปมาแบบขำ ๆ ก่อนจะยอมในที่สุด
- **ช่องพิมพ์ข้อความ** ให้เลือกอารมณ์ตอนนี้ (ชิปเลือกซ้าย-ขวา) และพิมพ์ข้อความเพิ่มเติมได้อิสระ
- **หลังบ้านดู log** สำหรับเจ้าของปราสาทเท่านั้น เข้าถึงได้ 2 ทาง (ดูหัวข้อถัดไป)

## การดู log ข้อความที่ถูกส่งเข้ามา

หน้านี้ถูกออกแบบให้ทำงานได้ 2 โหมด:

1. **เปิดเป็น Claude Artifact** (แนะนำ) — ถ้าเปิดผ่านลิงก์ artifact ของ Claude ระบบจะบันทึกข้อความทุกอันแบบเรียลไทม์ผ่าน `db` capability และจะโชว์แผง "หลังบ้านเจ้าของปราสาท" ให้อัตโนมัติเมื่อเจ้าของ (ผู้ publish) เปิดดู ถ้าอยากให้แอร์กดปุ่ม/พิมพ์ข้อความได้ด้วย ให้ตั้งค่าแชร์ลิงก์เป็น "Can interact" หรือ "Can edit" ก่อนส่งลิงก์ให้แอร์
2. **เปิดเป็นเว็บไฟล์ปกติ (เช่น GitHub Pages)** — จะไม่มี `db` ให้ใช้ ระบบจะบันทึกข้อความไว้ใน `localStorage` ของเครื่องที่กดส่ง และมีปุ่ม "คัดลอกข้อความ" กับ "ส่งเป็นอีเมลแทน" (ส่งเข้าอีเมลเจ้าของปราสาทโดยตรง) ให้ใช้แทน

กดปุ่มจุดเล็ก ๆ ท้ายหน้า (•) แล้วใส่รหัส `แอร์คือของขวัญ` เพื่อเปิดแผงหลังบ้านดู log ด้วยตัวเองได้ทุกเมื่อ (เปลี่ยนรหัสได้ในไฟล์ `index.html` ที่ตัวแปร `code.trim().toLowerCase()`)

## ปรับแต่งเพิ่มเติม
